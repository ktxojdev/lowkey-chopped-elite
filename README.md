# Lowkey Chopped Elite (LCE) 🚀

A high-performance, modern Next.js 15 web platform featuring an unblocked activity catalog, streaming entertainment engine, Llama 3.3 AI assistant, soundboard, and WebAssembly x86 virtual machines.

---

## 🌟 Key Features

- **🎮 Activities & Games Catalog**: Over 1,200+ offline-ready and proxied games with full WebGL, WASM, audio, and gamepad support.
- **🎬 Entertainment Hub**:
  - **YouTube Unblocked**: Server-side InnerTube search proxy with unblocked HTML5 cinema playback (Piped, YewTube, Nadeko, and F5 failover engines).
  - **Movies & TV Shows**: Multi-source streaming proxy powered by Cinesrc and Vidsrc engines.
  - **Anime & Manga**: Synced with Jikan and MyAnimeList.
  - **Live TV**: 25+ global news, sports, and entertainment streams.
  - **Books**: Instant search and EPUB reader via OpenLibrary.
- **🧠 Llama 3.3 (70B Instruct) Studio**:
  - Dedicated reasoning, code generation, and homework solving powered by Meta's Llama 3.3.
  - Direct support for local Ollama instances and custom Groq/OpenRouter keys.
- **💻 WebAssembly Linux & DOS VM**: Run Linux (Alpine), Windows 98, and FreeDOS directly inside the browser using v86 emulation.
- **🔊 Instant Soundboard**: 50+ instant sound effects and memes with custom audio controls.
- **🛡️ Stealth & Tab Cloaking**: Disguised by default as *Clever | Portal* with Google Classroom, Canvas, Drive, and Khan Academy cloaks.

## 🚀 Quick Start (Development)

### Requirements
- [Node.js](https://nodejs.org) (v18.18+ or v20+ recommended)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Local Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser!

### Windows 1-Click Launch
Double-click **`start.bat`** to automatically check dependencies and launch the local server.
